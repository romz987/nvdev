# Nvdev - персональный инженерный блог

Персональный инженерный блог на тему использования Neovim в качестве среды 
разработки с авторизацией и возможностью добавлять, редактировать и удалять контент.

В основе проекта:
- Интерактивный каталог плагинов с фильтрацией
- Возможность поиска и сравнения плагинов, выполняющих аналогичную задачу
- Гайды по сборке IDE на базе Neovim и конфигурационного фреймворка Nvchad
- Короткие гайды и обзоры по плагинам
- Конструктор готовых конфигураций

## Стек

HTML5  
CSS  
JavaScript  
Только нативные API браузера  
Без сборщиков и бандлеров  
Деплой на VPS  

## Запуск

Через локальный HTTP-сервер:  

```npm install -D lite-server```

```
"scripts": {
  "dev": "lite-server"
}
```

```npm run dev```

## Neovim плагины


| Категория (EN) | Категория (RU) | Описание |
|---|---|---|
| syntax | Синтаксис и подсветка | Парсинг и подсветка кода, навигация по синтаксическому дереву (tree-sitter и парсеры). |
| lsp | Языковые серверы (LSP) | Поддержка языков через LSP-серверы и LSP-инструменты: автодополнение, диагностика, навигация, рефакторинг; управление через Mason и nvim-lspconfig. |
| completion | Автодополнение | Движки автодополнения, сниппеты и источники подсказок (nvim-cmp и связанные плагины). |
| debugging | Отладка | DAP-клиент, UI отладки, виртуальный текст и адаптеры (debugpy, js-debug-adapter) для пошаговой отладки. |
| navigation | Навигация и редактирование | Быстрый поиск, переходы по тексту, мультикурсор, перемещение и дублирование строк и блоков. |
| interface | Интерфейс и оформление | UI-слой: темы, статуслайн, иконки, уведомления, отступы, подсветка, рендер Markdown, анимации. |
| formatting | Форматирование | Форматтеры и мост к ним (conform.nvim): black, prettier, stylua, dockerfmt и другие. |
| linting | Линтеры и диагностика | Линтинг кода и интеграция внешних линтеров в диагностику Neovim (nvim-lint, eslint_d, ruff). |
| ai | AI-ассистенты | ИИ-помощники внутри редактора (например, avante.nvim). |
| file-tree | Файловое дерево | Файловые менеджеры и обзор структуры проекта (nvim-tree.lua). |
| terminal | Терминал | Встроенный плавающий терминал NvChad (настраивается в chadrc.lua, раздел term); отдельных плагинов в каталоге пока нет. |
